# Historias de usuario
## HU1 - Registrar PQRS
Como ciudadano o cliente quiero registrar mi Petición, Queja, Reclamo o Sugerencia adjuntando evidencia para dejar constancia formal y recibir un número de radicado.

## HU2 - Consultar estado
Como ciudadano o cliente quiero consultar el estado de mi solicitud con el número de radicado para saber en qué punto del proceso está sin llamar o escribir de nuevo.
Criterios: sin autenticación; ingresar radicado; mostrar estado y respuesta si existe; error si no existe; no revelar otras PQRS.
